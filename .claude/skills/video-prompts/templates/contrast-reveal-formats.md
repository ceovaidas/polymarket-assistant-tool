# Contrast-reveal formats (5 viral reference reels studied 2026-11-02)

All five are 12-18 s, no talking, trending music, one white caption line at the top that changes per beat.
They all share one engine: show something bad / fake / mocked first, then a "VS..." swap, then a visual
spectacle with a person enjoying it. Frame 0 is already strange (a taped toy, a cardboard car, a dark road,
a covered table), so the question opens before 1 s.

## Rules taken from them
1. The caption IS the story; 2-4 short beats, each with one emoji. "VS..." on the swap.
2. The first version is bad in a funny way (DIY, cardboard, a mocking quote), never just a calm person.
3. The swap is shown with hands on the product (mounting it, strapping it on).
4. The payoff is pure visual: light, water, motion, then a person enjoying it for 2-3 s.
5. No dialogue. Natural sound + trending audio. Handheld phone footage.
6. CTA: a keyword comment only with a real ManyChat automation, else "Link in bio".
