# Template: DIY-fail opener + reused payoff (user's favourite, 2026-11-02, Voilaure shield)

The format the user praised most: "she builds her own version, it fails, then the real product works".
Once one full video exists, every new variant costs only ONE new start frame + ONE new clip (~840 credits
on Artlist: Nano Banana 2 90 + Wan 3.0 5 s 750). The payoff clips are reused.

## Structure (13-17 s, no talking, captions only)
| Beat | Caption | Clip |
|---|---|---|
| 0-5 s | "[DIY thing], attempt #N 🛠" / "My genius idea to save my mascara 🤓" / "I tried to BUILD my own …" | NEW: homemade contraption → water → it fails → visible damage (mascara streaks, raccoon eyes) → deadpan stare at the lens |
| 5-9 s | "VS..." | REUSED: real product put on (mirror shot) |
| 9-14 s | "What actually works 🤩" | REUSED: product doing its job (foam sliding off the shield, dry lashes, smile) |
| (14-16 s) | "Would you try it? 👀" | REUSED: end reaction (optional) |

## Rules that made it work
- **Premise check first:** before a new concept, check `hooks.md` (did we do it?) and run web searches
  (TikTok discover pages, press, shops) for the object + "lash"/"shower". If a big version exists, change
  the object or the twist. Log findings in a `research-*.md` file in this folder (first one:
  `research-lash-shower-2026-11-03.md`).
- **Vary pose, angle and moment** between openers (mid-build, lean-in close-up, mirror), not only the object.
- **Set packs:** each payoff pack has one look. Keep the opener in the SAME look as the clips it reuses:
  white towel + white marble (bottle / document-sleeve videos) or brown towel + travertine + brass
  (cups / goggles videos). The user noticed and liked the matching set.
- **Alternate packs** between consecutive variants so two posts in a row never end with the same clips.
- **Opener ideas used:** taped takeout lid, cut soda bottle + cling film, plastic cups as goggles,
  document-sleeve visor with bobby pins, pink swim goggles (raccoon mascara), crumpled foil visor ("Me protecting my $150 lash lift 🤡"). Vary the caption too, not only "attempt #N". Rejected: sink rinse (read as
  face washing), umbrella (no "she built it" story), welding helmet (no logic).
- **Content filter (Wan 3.0):** towel-in-shower frames with chest/shoulders get blocked. Make the start frame
  shoulders-up (face fills the frame); a blocked job costs nothing, re-crop the frame and retry.
- Show the start frame to the user before the clip; quote cost; generate only after "taip".
- Captions: Montserrat ExtraBold white with dark outline at the top; Noto emoji without the variation
  selector (🛠 not 🛠️) or it renders blank. Music is added by the user in Instagram.
