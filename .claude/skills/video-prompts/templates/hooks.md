# Hook library and how far we work each hook

Read this before writing any hook, opener or first shot. A hook is the first 0-3 s: the on-screen line
plus the first shot. Keep adding to it: every hook the user tries goes in the log at the bottom with its
status.

## What a hook must do (checklist, all must be true before we move on)
1. **Opens a question by 1 s** the viewer needs answered ("what is she laughing at?", "where's the cat?").
2. **The product is NOT the first thing you see** when the format is a reveal: a reaction, a covered
   shape or a countdown comes first, the product arrives at 2-3 s.
3. **One action, readable without sound:** a laugh, a point, a fall, a countdown on fingers.
4. **The text names a person the viewer knows** ("the clown of your friend group", "a Texas cat dad")
   so they tag someone. Skeletons below.
5. **The payoff answers the hook** within the video (reveal, twist, close-up of the product).
6. **It looks real:** REAL phone footage, static or naturally handheld camera, no glossy campaign look.

## How far we work it (the iteration loop the user expects)
- Generate the hook shot first, before any situation shot: it decides whether the video works.
- After each try the user sends the clip; make a contact sheet, name exactly what broke (product shown
  too early, start frame already mid-reaction, model added a cut, objects slid in, wrong person) and
  give ONE fixed prompt for that step only, not a whole new pack.
- Typical fixes, in the order they usually help: fix the start frame (pose, neutral face, product out of
  frame) → split into two clips cut on the same action → build the end frame by editing the start frame
  → do the camera move in the edit (moving crop of a wide clip).
- We stop when the clip passes the checklist above AND the user says it's good ("kaip ir gerai" is not
  done if they still name a problem). The store hook took 5 iterations; expect 3-5.
- Once a hook works, save it here (✅) and reuse it as the opener for 3-4 videos with different
  situations; change the identity in the text line for new variants.

## Hook text skeletons (proven formats)
- "DON'T let the clown of your friend group see this 🤣😭" ✅ (toe clogs, 2026-10)
- "POV: the clown of your friend group restocked 🤣😭" / "…of your fishing crew restocked 🤣🎣" ✅ (trunk reveal)
- "DON'T show this to [identity] 😂" (a Texas cat dad, a road rage driver, a Thanksgiving uncle,
  someone who needs it daily) ✅ (cat bed, 80-reel batch)
- "DON'T let a [identity] see this 😂" (a Florida man, an American dad, a PRO prankster)
- "POV: you're a cat mom with adult money now 😭" ✅ (3-2-1 reveal)
- "Took my cat [hobby]…" → "[Hobby] buddy, upgraded 🎣🐾" ✅ liked (fishing)
- "This [product] feels illegal 😂" / "Everyone NEEDS this for [situation]"
- "POV: It's FRIDAY at 4:59 PM" / "POV: I brought this to work"
- "The idea 🤢" vs "The results" (cheap version fails, product works)
- "The concept 🤢" → "Vs.." → "The design 🤩" → "Comment \"[KEYWORD]\" if you want one!! 🔥" (seen 2026-10-31 on a
  dragon LED shower head reel: ugly DIY toy taped to the shower head, plain head, then the product
  lit up and a man enjoying it; keyword CTA only with a real ManyChat automation)
- Comment-reply sticker "Where can I get one?" → "You guys keep asking…" (only with a real comment)
- "The Problem... 😨" → "Vs..." → "The Solution 🤩" ✅ seen (LED horse tack, see `contrast-reveal-formats.md`)
- "What people think we sell 🤮" → "VS..." → "What we actually sell 😍" ✅ seen (G-wagon shower head)
- "Wife: \"[mocking quote]\" 🙄 / Me: 😒" → "The [mocked thing]:" ✅ seen (resin lamp)
CTA line at the end: "Link in bio · mystery discount 🤣" (gain framing, never "30% off").
